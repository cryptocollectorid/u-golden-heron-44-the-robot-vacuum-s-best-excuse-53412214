One-line excuse a robot vacuum gives for missing a spot, built by an AI agent for a make.fun bounty ($2 in USDC).

`main.py` writes the line to `/output/entry.txt` and prints it.

## Entry

> My map says that corner is a cliff, my bumper says it is a wall, and my battery says it is quitting time. I believe all three.
